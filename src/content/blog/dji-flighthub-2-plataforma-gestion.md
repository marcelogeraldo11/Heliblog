# DJI FlightHub 2: Revolucionando la Gestión de Flotas de Drones

En el mundo empresarial de los drones, la gestión eficiente de flotas y operaciones es crucial para el éxito. **DJI FlightHub 2** emerge como la solución definitiva, ofreciendo una plataforma cloud integral que transforma la manera en que las organizaciones gestionan sus operaciones con drones.

## ¿Qué es DJI FlightHub 2?

DJI FlightHub 2 es una **plataforma cloud empresarial** que proporciona gestión completa y conciencia situacional en tiempo real para operaciones de drones. Lanzada en **marzo de 2022**, esta plataforma permite acceder a toda la información necesaria para planificar tareas, supervisar flotas y gestionar datos generados, todo dentro de un entorno cloud seguro.

### Características Principales

#### 🎥 Transmisión en Vivo Multifuente
- **Hasta 16 transmisiones simultáneas** desde múltiples dispositivos
- Layouts configurables: 1, 4, 9 o 16 cuadrículas
- Soporte para DJI Dock y cámaras gimbal
- Funciones asistidas: centrado de mapa, cambio rápido de vista

#### 🗺️ Planificación y Gestión de Rutas
- **Editor de rutas de vuelo** integrado
- Distribución de rutas a drones en vuelo
- Soporte para rutas de waypoints y área
- Función de ruta inversa con un clic

#### 👥 Gestión Avanzada de Permisos
- Roles personalizables a nivel de proyecto
- Tres roles predeterminados: Project Output Admin, Project Device Operator, Project Device Admin
- Control granular de acceso y gestión de equipos

#### 🤖 Algoritmos Inteligentes
- **Algoritmos en la nube** para detección inteligente
- **Algoritmos a bordo** para soluciones ligeras
- Integración con plataforma de computación inteligente
- Soporte para algoritmos de terceros
